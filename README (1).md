# EstrategiaOS — Plataforma de Gestão Estratégica

Plataforma web para acompanhar a execução da estratégia do escritório de advocacia previdenciária de Thayne Oliveira.

## ✨ Recursos

- **Dashboard em tempo real** — Painel de controle com KPIs
- **Plano por setor** — Tarefas com status (A fazer, Em andamento, Suspenso, Cancelado, Concluído)
- **Registro semanal** — Anote investimento, leads, contratos e retorno
- **Avaliação do Claude** — Diagnóstico inteligente baseado nos seus dados

## 🚀 Como usar

### Local (seu computador)
1. Abra `plataforma-github.html` em qualquer navegador
2. Dados salvos automaticamente (localStorage)
3. Para avaliação do Claude: clique "⚙️ Configurar API" e insira sua chave

### GitHub Pages (site público)
1. Faça upload dos arquivos para um repositório GitHub
2. Ative Pages nas configurações
3. Acesse em `https://seu-usuario.github.io/seu-repositorio`

## 🔐 Segurança da API Key

✅ Armazenada APENAS no seu navegador (localStorage)
✅ Nunca é enviada para servidores terceiros
✅ Use em computadores confiáveis

Obter chave: [console.anthropic.com](https://console.anthropic.com)
